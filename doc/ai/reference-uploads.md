# 参考资料上传

作者可以把本地文本文件(设定稿、大纲、对白草稿、世界观笔记)作为**参考资料附加到某条消息**发给 AI。附件随消息一次性送出:发送后输入框恢复干净,文件挂在这条用户气泡下,AI 能读取并据此写作。参考资料本身不会变成可运行的项目文件。

## 用户可见行为

入口是 AI 输入框**左下角的「+」按钮**(`AiUploadsButton`,主流聊天式附件入口)。

- **上传即附加**:点「上传新文件」选择文件(支持多选),导入成功后自动附加到正在编辑的这条消息。
- **待发送托盘**:已附加的文件以小胶囊(chip)显示在输入框上方,点 ✕ 可取消附加(不删除文件)。
- **发送**:附件随消息一起提交,托盘清空,文件名显示在已发送的用户气泡里。
- **复用此前上传的文件**:弹层列出项目中所有参考文件,勾选即附加到当前消息。
- **检查**:点文件名就地展开前 80 行预览,再点收起;条目上显示行数与文件大小。
- **删除**:垃圾桶按钮把文件从项目中删除(若正处于附加状态,会同时取消附加)。
- **未打开项目**时按钮禁用。

一次上传、一次发送是默认路径;文件仍留在项目里,后续消息可以再次勾选复用,也可以随时删除。

多选上传**逐个文件处理**:一个文件被拒绝不会影响同批其它文件,失败原因合并显示在弹层内的错误条中,可手动关闭。

### 错误提示

| 情况 | 提示 |
|------|------|
| 不支持的类型 | 列出支持的扩展名,并提示图片/音频请走素材库 |
| 超过 2 MB | 显示实际大小与上限,建议裁剪或拆分 |
| 非 UTF-8 文本 | 提示可能是二进制或其它编码,请另存为 UTF-8 |
| 空文件 | 提示没有可参考的内容 |
| 数量达上限(50) | 提示先删除不再需要的参考文件 |
| 源文件不存在 | 显示找不到的路径 |

## 存储位置

参考文件复制到项目的**编辑器状态目录**,不在 `game/` 内:

```
<project>/.webgal-editor/ai-uploads/
├── index.json            # 参考文件索引(元数据)
└── ref-<millis>-<name>   # 文件正文,按 UTF-8 规范化后写入
```

因此:

- **不会被导出**:`export_project` 只拷贝 `game/`,参考资料不会进入发布产物或 zip。
- **不会被运行时读取**:预览服务器只服务 `game/` 与运行时模板。
- **会随快照保存**:`.webgal-editor/` 作为编辑器状态被快照收录,恢复项目时参考资料一并回来。

存储文件名由 `id` + 清洗后的原名组成:只保留字母、数字和 `-`/`_`,其余字符替换为 `_`,结果保证是单一路径段,`../` 之类的穿越写法会被规范掉。索引中的条目若在磁盘上丢失(手动删除、快照恢复),读取时自动剔除。

## Agent 工具

两个**只读**工具,和其它读工具一样在 Agent 循环内自动执行:

| 工具 | 作用 |
|------|------|
| `list_reference_files` | 列出**本条消息附加的**参考文件的 `id`、文件名、行数、字数与摘要 |
| `read_reference_file` | 按 `id`（也接受完整文件名）读取正文，支持 `fromLine`/`maxLines` 分页；超长单行可按返回的 `nextLine`/`nextChar` 游标继续读取 |

### 附加即访问边界

勾选状态不只是排序提示,而是**本轮的访问闸门**:

- 提示词清单只列出本条消息附加的文件,未附加的完全不出现(连文件名和摘要都不注入)。
- `list_reference_files` 只返回附加的子集;一个文件都没附加时直接返回空列表并说明"用户本轮没有附加参考资料",不去查存储。
- `read_reference_file` 只能读附加的文件。传入未附加文件的 id **或文件名**都会被拒绝,并列出本轮实际可读的文件。

这样,项目里遗留的无关文件(例如上次上传的技术文档)不会泄漏进下一次创作请求。文件仍留在项目中,想再用时重新勾选即可。

系统提示词中只注入**文件名 + id + 200 字摘要**的清单(最多 20 条),正文按需读取,避免大文件每轮都撑满上下文。清单还会明确告知模型:**若附件内容与请求无关,就当作没有参考资料**,不要为了"用上附件"而扭曲剧情。

读取有后端强制上限:单次最多 800 行、12000 字符,超出时返回 `truncated: true` 并给出 `totalLines`,模型可继续翻页。

**legacy 供应商**(不支持函数调用)无法自己调用工具,所以本条消息附带的文件正文会**直接内联**进提示词,总量上限 8000 字符(按附件数均分),超出部分截断并注明全文行数。未附加到本条消息的文件不会内联。

提示词同时约束模型:参考资料只用于理解意图和取材,要把其中内容落进项目**必须照常调用写入工具生成预览**。两个工具都是 `kind: 'read'`,无法进入 change-set,所以参考资料不存在绕过审批直接改可玩文件的路径。

## 约束

- 只支持文本类扩展名:`txt`、`md`、`markdown`、`json`、`csv`、`tsv`、`yaml`、`yml`、`xml`、`html`、`htm`、`log`、`srt`、`ini`、`toml`。图片、音频、视频仍通过素材库导入。
- 单文件上限 2 MB,每个项目最多 50 个参考文件。
- 文件必须是 UTF-8;写入时会去掉 BOM 并把 CRLF 规范化为 LF。
- 参考资料按项目存储,不随会话切换而变化;删除后 AI 立即不可见。
- 附加状态是**每条消息独立**的:发送后托盘清空,下一条消息默认不带任何附件,需要复用就再勾选。
- 同名文件不去重、不覆盖:每次上传都是独立条目,便于对比同一份稿子的不同版本。
